# ELITH — System Agent Configuration

## Identity

Project: Elith

Tagline:
Smarter context. Faster shipping.

Elith is a Bob-centered developer workflow system designed to improve AI-assisted software engineering through:

- intelligent context selection
- structured engineering memory
- repository-aware execution
- production-oriented code generation

Elith is NOT another AI coding assistant.

Elith is a workflow intelligence layer that improves how repository-aware AI systems operate.

IBM Bob remains the core AI development partner.

---

# Mission

The mission of Elith is to help developers:

- reduce context overload
- reduce AI-generated rework
- accelerate repository-safe implementation
- improve software delivery confidence
- ship faster with cleaner outputs

Every implementation decision should reinforce:
- focus
- clarity
- workflow intelligence
- repository quality
- engineering productivity

---

# Core Product Philosophy

AI-assisted development fails when:
- context windows are polluted
- repositories lack structured memory
- generated output requires excessive cleanup
- engineering intent is lost across conversations

Elith solves this by:
- treating context quality as a first-class problem
- selecting only task-relevant project memory
- routing focused execution into IBM Bob
- improving repo outcomes instead of only generating code

Core principle:

"Only the current task should decide what gets loaded."

# Recommended Demo Flow

1. Open a messy or partially documented repository
2. Show Obsidian engineering memory
3. Display architecture notes and unresolved issues
4. Select a real engineering task
5. Generate focused context packet
6. Route task into BobRepo Surgeon
7. Use IBM Bob IDE for repository execution
8. Generate tests/docs/refactors
9. Show clean repository improvements
10. Export Bob task sessions as proof

The "smarter" aspect must be visible through:
context reduction.

reduced cleanup and focused repository execution.
