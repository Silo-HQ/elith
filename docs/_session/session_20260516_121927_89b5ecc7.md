## 3️⃣ How They Interact

1. **User → UI**  
   *Web*: User types a prompt in the bottom bar or selects an operation.  
   *TUI*: User hits `Enter` in the chat input.

2. **UI → Backend**  
   *Both UIs call `POST /api/execute`* with the chosen model, operation and repo path.  
   The backend responds with a `session_id`.

3. **UI → Backend (Streaming)**  
   After receiving the session id, each UI opens an SSE connection to `GET /api/stream/{session_id}`.  
   The backend pushes incremental output (type `output`) and a final `done` event.

4. **UI → UI**  
   *Web*: The React store (`elithStore`) receives streaming data via a WebSocket or fetch‑stream and updates `liveOutput`.  
   *TUI*: The Textual app receives SSE events in `stream_response` and appends messages to the chat panel.

5. **Result / Proposal**  
   When a session finishes, UI can request `GET /api/proposals/{session_id}` or `GET /api/results/{session_id}` to show architecture proposals or a summary.

6. **Shared State**  
   Both UIs expose similar concepts (models, repo path, session status) but keep them in their own language‑specific stores.

## Quick‑Start for a New Developer

1. **Run the backend**  
   ```bash
   pip install -r requirements.txt
   uvicorn backend.main:app --reload  # (or whatever entry file)
   ```

2. **Start the web UI**  
   ```bash
   cd frontend
   npm install
   npm run dev  # opens http://localhost:3000
   ```

3. **Start the TUI**  
   ```bash
   python tui/app.py  # or `python -m tui.app`
   ```

4. **Explore the code**  
   *Frontend*: `frontend/src/components/` and `pages/`.  
   *TUI*: `tui/screens/`, `components/` and `app.py`.  
   *Backend*: Look at the API routes (not in snippet) to understand payloads.

5. **Add a new feature**  
   *Pick the UI you’re working on.*  
   *Create a new component or screen.*  
   *If it needs backend data, add an endpoint in the FastAPI app and call it from the UI.*  
   *Make sure to update the shared design spec if colors or layout change.*

6. **Testing**  
   *Web*: `npm run build` for type checks and bundling.  
   *TUI*: Run the app and test keyboard shortcuts, command parsing (`/help`, `/models`, etc.).  
   *Backend*: Write FastAPI tests with `pytest` and `httpx.AsyncClient`.
