## 3. How They Interact

1. **Bootstrapping**  
   * `src/index.tsx` mounts `<App />` into Ink. Ink turns React rendering into terminal output.

2. **User Input**  
   * The user types in `<ChatInput />`. When they press **Enter**, the input value is sent to `App.handleUserInput`.

3. **Command Parsing**  
   * `handleUserInput` checks if the text starts with `/`. If so, it delegates to a command handler (`handleCommand`).  
   * Commands like `/help`, `/models`, `/model <name>`, `/clear`, and `/repo <path>` update the global state or call API functions.

4. **API Interaction**  
   * For non‑command messages, `App` calls `api.execute()` to send the user prompt.  
   * While waiting, `<ThinkingPanel />` is rendered (spinner).  
   * `api.execute()` returns a **Server‑Sent Events** stream (`EventSource`). Each event is parsed and appended to the chat history via `App.addMessage`.

5. **Rendering**  
   * `<MessagesPanel />` iterates over the message array from state and renders each entry.  
   * If a message is of type `diff`, `<DiffViewer />` is used; if it’s an approval prompt, `<EditApproval />` appears.

6. **Status Updates**  
   * The current model, repo path, and other contextual info are kept in state and displayed by `<StatusBar />` or `<EnhancedStatusBar />`.

7. **Screens**  
   * `App` holds a `currentScreen` state (`welcome`, `chat`, etc.).  
   * On start it shows `<Welcome />`; after the first user interaction it switches to the chat screen.
