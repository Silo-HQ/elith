# Examples

These are demo projects generated with Elith to showcase end-to-end agent capabilities. They are not part of the core Elith codebase.

## Available Examples

- **todo-app/** - A full-stack todo application demonstrating Elith's code generation capabilities
- **itinerary-app/** - An itinerary planning application showcasing multi-agent collaboration

Each example is self-contained with its own README and setup instructions.
